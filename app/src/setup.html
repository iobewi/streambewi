Configurer StreamBeWI

Connectez votre radio à un réseau Wi-Fi 2,4 GHz. Vous pouvez aussi utiliser Improv avec ESP Web Tools par USB.

Laissez vide pour un réseau ouvert.

Attention : pendant la vérification, le Wi-Fi de StreamBeWI change de canal et votre appareil peut être déconnecté de StreamBeWI-Setup. Si cela arrive, rejoignez de nouveau ce réseau : cette page affichera le résultat. Après confirmation, débranchez puis rebranchez StreamBeWI pour activer la radio USB.
